## F1 · IBM: Training Data
- url: https://www.ibm.com/topics/training-data
- nombre: IBM, What is Training Data? (en inglés)
- idioma: en
- año: 2025
- lecciones: Los datos; Aprendizaje automático

- D1: Los datos de entrenamiento son la información con la que se enseña a un modelo de aprendizaje automático a predecir y reconocer patrones (IBM, 2025).
  > Training data is information that is used to teach a machine learning model how to make predictions, recognize patterns or generate content.
- D3: El aprendizaje supervisado usa datos con etiqueta y el no supervisado usa datos sin etiqueta (IBM, 2025).
  > Supervised learning uses labeled data, while unsupervised learning uses unlabeled data.
- D4: Los datos de mala calidad introducen ruido y sesgo y le impiden al modelo hacer predicciones precisas (IBM, 2025).
  > Poor quality data can introduce noise and bias, which prevents machine learning models from making accurate predictions
- D7: El aprendizaje supervisado usa conjuntos de datos etiquetados para entrenar modelos que identifican patrones (IBM, 2025).
  > Supervised learning is a machine learning technique that uses labeled datasets to train AI models to identify the underlying patterns across data points.
- D8: El aprendizaje no supervisado descubre por sí solo la estructura de datos sin etiquetar (IBM, 2025).
  > Unsupervised learning models work on their own to discover the inherent structure of unlabeled data.
- D10: Ejemplo del supervisado: detectar spam con miles de correos etiquetados por personas como spam o no spam (IBM, 2025).
  > To teach a model to identify spam, one could expose it to a dataset comprised of thousands of emails, each labeled by humans as either “spam” or “not spam.”

## F10 · Wikipedia en español: Red neuronal artificial
- url: https://es.wikipedia.org/wiki/Red_neuronal_artificial
- nombre: Wikipedia en español, Red neuronal artificial
- idioma: es
- año: 2025
- lecciones: Redes neuronales explicadas sin fórmulas

- D11: Una red neuronal artificial es un modelo inspirado en la estructura y función de las redes neuronales biológicas de los cerebros animales (Wikipedia, 2025).
  > inspirado en la estructura y función de las redes neuronales biológicas en los cerebros animales
- D12: Las neuronas se agrupan en capas: la de entrada, la de salida y capas intermedias u ocultas (Wikipedia, 2025).
  > Las señales viajan desde la primera capa (la capa de entrada ) hasta la última capa (la capa de salida ), posiblemente pasando por múltiples capas intermedias ( capas ocultas )
- D13: Cada conexión tiene un peso que se ajusta durante el aprendizaje (Wikipedia, 2025).
  > La fuerza de la señal en cada conexión está determinada por un peso, que se ajusta durante el proceso de aprendizaje.
- D14: Una red neuronal profunda es la que tiene al menos dos capas ocultas (Wikipedia, 2025).
  > Una red se denomina típicamente red neuronal profunda si tiene al menos dos capas ocultas.
- D15: Las neuronas artificiales solo modelan "vagamente" las neuronas del cerebro: es una simplificación, no una copia (Wikipedia, 2025).
  > Una ANN consta de unidades o nodos conectados llamados neuronas artificiales, que modelan vagamente las neuronas del cerebro.
